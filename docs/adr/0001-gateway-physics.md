# Fixed panels and gravity-aligned bodies
Gateway transforms use orthonormal right/up/normal frames and a local half-turn: (-x,y,-z). This preserves speed and rotates orientation, offset and velocity, including floor-to-wall changes. We keep the player's body upright after traversal to preserve dependable movement; camera forward transforms then returns to a gravity-aligned yaw/pitch. This differs from a freely rotating rigid body.

Placement snaps to authored eligible panels so collision apertures have certified clearance. Arbitrary-wall cutting would introduce ambiguous support edges and needs a more general solver. Swept plane crossings run before axis-separated AABB collision, with 120 Hz substeps and exit clearance checks. Bodies ignore backing colliders only inside a linked, fitting aperture. A 0.12 s destination guard prevents immediate bouncing; motion away from the opening still collides normally. Portal output offsets include the upright body's normal extent.
